# ELARA One 中文六区块 landing page 设计规格

## 目标

将 `/zh/` 的 ELARA One 页面从“安静的智能指环概念介绍”重构成一条完整的购买叙事：

> 我喜欢它 → 它适合我 → 原来这么小里面还有这么多技术 → 它真的懂我 → 这些靠谱的人在替我做好一切 → ¥59,500 起，好像确实就该是这个价。

主要受众是希望在工作、穿搭和身体节律之间保持从容的都市女性。页面首先建立拥有欲，其次解释适配感与技术，最后给出购买和送礼入口。

## 范围与边界

- 只完整重做中文 `zh` landing surface；英文和日文保留现有内容与结构。
- 保留现有 hand-only 摄影、透明全幅 Hero、移动端图片与文字不重叠的视觉契约。
- 保留 React/Vite、当前 locale 路由、local-only preview 表单和 Sites 打包方式。
- 不修改 `.openai/hosting.json`、`worker/index.js`、`scripts/prepare-sites-build.mjs`、`tests/sites-worker.test.mjs`。
- 不新增真实订单、支付、库存、邮件发送或用户数据持久化。
- 不发布未经 clearance 的“世界最细”或 No.1 声明。

## 信息架构

### 01 第一屏：身份 + 欲望

使用现有全幅 hand-only hero 图片，导航和文案透明浮在图片上。文案只回答“它属于怎样的我”，不进入 sensor specification。

- 主标题方向：`一枚属于你的智能戒指。`
- 辅助句方向：`它先是戒指，然后才是一件安静的科技。`
- CTA：`了解 ELARA`、`预约体验`
- Hero 下方用一句短的 ownership statement 承接：`每天都戴得上的东西，才有资格真正懂你。`

### 02 设计：它首先是一枚戒指

锚点 `#design`。使用产品静物图与两条产品线：`Standard 素圈`、`Design 设计款`。视觉重点是大号 `6 mm`，旁边用短标签解释 `US 6+`、`钛合金内圈`、`日常穿搭不违和`。

`6 mm` 在原型中作为目标宽度展示；`世界最细` 只作为内部 claim-clearance 备注，不进入页面。价格在本区块首次出现为 `参考售价 ¥59,500 起`，同时标注产品仍为 concept / 规格待最终确认。

### 03 科技之美：科技应该适应你

锚点 `#technology`，全页视觉中心。采用深梅紫背景和一个简化的 ring-stack CSS/HTML 视觉，不做赛博电路板，也不把页面变成参数表。

核心标题：`真正先进的科技，不需要你适应它。它只负责适应你。`

只展示三项足以建立想象的内部能力：

- `单组三色光 PPG`：安静地感知身体节律的变化。
- `振动马达`：需要时给你一个不打扰别人的回应。
- `6 mm 的容纳`：把复杂技术藏进日常佩戴的轮廓里。

每项技术都用“对我有什么用”收尾，避免使用精度、医疗效果、续航或准确率等未经验证的数字。

### 04 它每天为我知道什么

锚点 `#daily`。以现有 App still-life 为主视觉，旁边做四个日常场景卡片：`压力`、`月经 / 身体周期`、`活动`、`睡眠`。每张卡只表达一个生活问题，例如“今天为什么比平时更累”，并连接到一条简短的每日洞察。

核心表达：`它替我留意那些我自己没空留意的变化。`

不展示 sensor count、原始曲线或仪表盘密度；保留“每日一句、可行动”的感觉。周期内容使用“观察与理解”语言，不做诊断、预测或治疗承诺。

### 05 为什么值得相信

锚点 `#trust`。不使用“优秀女性科学家监制”这样的总括性背书，改为三张人物/职责卡：

1. `女性健康体验设计`：东京大学女性科研人员参与产品与女性健康体验设计，说明她们为什么加入、关注什么。
2. `技术团队`：展示感知、嵌入式与产品工程背景，说明如何把技术藏进 6 mm 轮廓。
3. `验证从真实样机开始`：展示真实样机、佩戴场景和验证方法；没有公开姓名或结果时明确标为“正式发布时披露”。

这一章建立的是方法与责任感，不制造排名、认证、临床效果或虚构的个人履历。

### 06 购买 + Gift

锚点 `#buy`。在同一购买区内提供 Standard / Design 选择、颜色、刻字和 `¥59,500 起` 参考售价；若某个变体的最终价格尚未确认，使用“参考售价 / 起”而不编造差价。

右侧或下方单独放置 `送给重要的人` Gift 入口，展示完整的静态送礼路径：选择戒指 → 添加刻字 → 写 NFC 心意卡 → 预览收件人收到的内容。Gift 入口可以展开为本地交互面板，但不提交真实订单。

最终 CTA 是 `预约体验` / `进入 Gift 预览`，沿用当前 local-only 表单的透明说明。

## 组件与数据设计

- 在 `src/App.jsx` 增加一个中文专用页面渲染分支，例如 `ChineseLanding`；当 `locale === "zh"` 时使用新结构，`en` 与 `ja` 继续使用现有组件树。
- 在 `src/content.js` 的 `zh` 记录中增加中文专用 `landing` 数据对象；保留现有必需键以维持内容测试和旧渲染兼容。
- 新组件使用 `zh-*` 前缀 class，避免新视觉规则改变英文/日文页面。
- `src/styles.css` 增加中文页面专属 tokens、desktop/tablet/mobile layout、hover/focus/reduced-motion 规则；不重写旧页面的通用规则。
- 购买选择和 Gift 展开状态只保存在 React state，不写入 localStorage、不调用网络。
- 图片继续使用现有素材：hero/hand-only 图片用于欲望，`ring-finishes.jpg` 用于设计与购买，`daily-insight-device.jpg` 用于每日理解；科技和 Gift 视觉使用 CSS/HTML，以避免无必要的图片生成。

## 交互与可访问性

- Header 锚点分别落到 `#design`、`#technology`、`#daily`、`#trust`、`#buy`。
- Standard / Design 使用可键盘操作的 button 或 radio semantics，当前选择具备 `aria-pressed` 或 `aria-checked`。
- Gift 展开按钮使用 `aria-expanded` 与 `aria-controls`，展开后焦点仍可顺序进入内容。
- 保持 skip link、语义 landmark、单一 `h1`、递进的 `h2/h3`、图片 alt、visible focus 和 reduced-motion 支持。
- 预约表单继续展示空值/格式错误、成功和“仅本地预览”状态，不把本地状态称为真实订单或预约完成。

## 验证计划

- 更新内容测试，验证中文 `landing` 的六个区块、价格/规格边界文案和 Gift 数据不为空；验证英文、日文必需结构仍存在。
- `npm test`
- `npm run build`
- `npm run test:sites`
- 启动本地服务器后，在 desktop 与 390px mobile 检查：Hero 全幅、科技章完整、购买区可达、Gift 展开、无横向溢出、无图片覆盖文字。
- 检查 `/zh/` 作为中文主页面，切换到 `/en/` 与 `/ja/` 后旧页面仍可渲染。
- 完成浏览器验证后更新 `design-qa.md`，只有无 P0/P1/P2 视觉问题时才写入 `final result: passed`。

## 验收标准

- 中文页面按照六个区块形成连续购买叙事，而不是旧页面章节的简单换名。
- 第三章成为明显的品牌记忆点，技术解释稀疏、温和、服务于佩戴者。
- `6 mm`、`US 6+`、钛合金内圈、`¥59,500 起`、颜色、刻字与 Gift/NFC 路径均可在页面中找到，并保留 concept / final-spec 边界。
- 不出现未经 clearance 的“世界最细”、No.1、医疗功效、临床准确率或虚构背书。
- 英文和日文页面不被中文视觉与文案改动破坏。
- Sites 交付所需文件、构建产物和现有 worker 行为保持完整。
